Permanomics

Twenty-eight interactive models — money, energy, and what falls between them

Financial systems run on rules about money: what counts as an asset, how debt is created, what gets priced. Physical systems run on thermodynamics and biophysical limits — rules that don't negotiate. These models explain both. The incompatibility between them is what this series is about.
